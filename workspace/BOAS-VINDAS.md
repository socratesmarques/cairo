# Workspace do Cairo

Coloque aqui arquivos que os agentes podem consultar. No modo normal, peça para
listar os arquivos ou ler este documento. O modo swarm divide a análise entre
desenvolvimento, pesquisa local e sistema, com revisão ao final.

Escrita em arquivos depende de CAIRO_ALLOW_WRITE=true. Nunca coloque credenciais
ou arquivos privados que não deseja enviar ao provedor de IA neste diretório.
